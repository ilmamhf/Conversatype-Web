# Conversatype — Future Roadmap & Growth Strategy

## 1. Feature: AI English Fluency Test ("Blind Mode")
- **Problem**: In standard typing mode, the user copies the exact text shown. In real life, speakers must formulate their own thoughts on the fly.
- **Solution**: "Blind / Fluency Challenge" mode:
  1. The user is presented with an NPC dialogue bubble.
  2. Instead of copying exact text, the user receives an objective prompt (e.g., *"Politely decline the proposed time and suggest meeting Tuesday at 2 PM"*).
  3. The user types their own reply from scratch.
  4. An AI/ML model evaluates the response in real time across four pillars:
     - **Grammar & Vocabulary Accuracy**
     - **Tone & Politeness Appropriateness**
     - **Natural English Phrasing**
     - **Typing Speed (WPM)**

---

## 2. Multilingual Support (i18n)
- Expand conversational typing scenarios to non-English target languages:
  - **Spanish**: Casual texting, traveling in Latin America/Spain.
  - **Japanese**: Romaji-to-Kana conversion practice, polite keigo workplace chat.
  - **French**: Casual messenger slang, Parisian cafe ordering.
  - **Indonesian**: Natural conversational slang, workplace Slack.
  - **German & Mandarin**: Business and daily conversational practice.

---

## 3. Global Daily Challenge & Leaderboards
- **Daily Seeded Conversation**: A Wordle-style daily conversation where every player worldwide types the exact same scenario.
- **Backend Architecture**: Supabase (PostgreSQL + Row-Level Security + Edge Functions) for instant cheat-verified leaderboards and user profiles.
